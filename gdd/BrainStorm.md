
#Game 

---
- Resumen del juego
Titulo: Por determinar
Genero: FPS, Gestión negocios ETC.
Plataforma: PC
Idea principal: Juego centrado en la creación y gestión de una mafia que intenta dominar una ciudad. 

- Jugabilidad
Mecánicas Principales: Sandbox, gestión negocios, gestión mafia, shooter, guerra de bandas, etc.
Objetivo: Dominar toda la ciudad. posibilidad de expansión a otros mapas????

- Diseño de niveles
Nivel 1: Test, Este nivel servirá para probar todas las mecánicas que puedan introducirse en el juego.

Nivel 2: Tutorial / nivel DEMO, este nivel será un pequeño pueblo que servirá como tutorial para aprender las mecánicas principales del juego y como prologo para dar contexto al jugador de como comienza la posible historia. Este nivel también servirá como MVP para decidir si el proyecto es viable.

En este nivel tendremos un pequeño pueblo con unas cuantas calles nada mas, tendrá una banda rival.

Nivel 3: Este nivel será el mapa principal del juego, su extensión aun esta por decidir.

## **1. Mecánicas centrales**

- [ ] **Sistema de combate**: armas cuerpo a cuerpo y a distancia, animaciones, daño, hit detection.
    
- [ ] **IA enemiga**: patrullas, detección del jugador, combate, huida.
    
- [ ] **Sistema de salud**: para el jugador y enemigos, con HUD y efectos visuales.
    
- [ ] **Sistema de muerte y respawn**: animaciones, reinicio de nivel o checkpoint.
    

##  **2. Mundo y progresión**

- [ ] **Mapa de ciudad dividido en barrios**: cada uno con estilo visual, enemigos y desafíos únicos.
    
- [ ] **Sistema de conquista**: al completar objetivos en un barrio, se marca como conquistado.
    
- [ ] **Misiones principales y secundarias**: con objetivos claros, recompensas y narrativa.
    
- [ ] **Sistema de guardado/carga**: progreso, inventario, posición del jugador.
    

## **3. Interacción y UI**

- [ ] **Menú principal y opciones**: nueva partida, cargar, ajustes.
    
- [ ] **HUD completo**: salud, munición, minimapa, objetivos.
    
- [ ] **Mejoras al inventario**: categorías, filtros, íconos, descripción de objetos.
    
- [ ] **Sistema de diálogo o interacción con NPCs**: para misiones, historia o comercio.
    

## **4. Diseño técnico y escalabilidad**

- [ ] **Uso de ScriptableObjects para enemigos, armas, misiones**.
    
- [ ] **Sistema modular para misiones y eventos**: fácil de expandir.
    
- [ ] **Gestión de escenas por barrio**: carga y descarga eficiente.
    
- [ ] **Optimización de colisiones y físicas**: especialmente en entornos urbanos.
    

##  **5. Audio y ambiente**

- [ ] **Sonidos de ambiente por barrio**: tráfico, música local, multitudes.
    
- [ ] **Efectos de sonido para armas, pasos, colisiones**.
    
- [ ] **Música dinámica**: cambia según combate, exploración o conquista.
    

**6. Pruebas y pulido**

- [ ] **Sistema de debug para misiones, IA y colisiones**.
    
- [ ] **Pruebas de rendimiento en distintos barrios**.
    
- [ ] **Feedback visual y sonoro para cada acción importante**.
    
- [ ] **Balance de dificultad y ritmo de juego**.
