Esta herramienta es un editor de texto que suele venir instalado en linux.

Sus comandos son:
- I es el insert mode con el cual se puede escribir en el documento.
- En el modo normal (Fuera de insert mode) se puede hacer uso de los comandos 
	- x para cortar un carácter
	- dw para cortar una palabra
	- dd para cortar una línea
	- yw para copiar una palabra
	- yy para copiar una línea
	- p para pegar
- En el modo normal también se puede establecer el numero de veces que se va a realizar uno de los comandos anteriores por ejemplo 4yw para copiar 4 palabras a la vez
- Podemos pulsar : para introducinos en el command mode:
	- :1 para saltar a una linea expecifica
	- :w para guardar el fichero 
	- :q para salir 
	- :q! para salir sin guardar 
	- :wq para guardar y salir
